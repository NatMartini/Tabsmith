## Preset failures

| Scenario | Error code | Next step offered |
|---|---|---|
| f01-config-typo | `E_CONFIG_UNKNOWN_FIELD` | did you mean `epochs`? fix the spelling; docs/configuration.md lists every setting |
| f02-unknown-category | `E_UNKNOWN_CATEGORY` | map the value to a known category, or retrain on data that contains it (or with preprocess.unknown_category = "ignore") |
| f03-missing-column | `E_SCHEMA_MISSING_COLUMN` | add `shift` to the input (missing values are imputed as in training); the bundle's input.schema.json lists every field |
| f04-cardinality-budget | `E_CARDINALITY_BUDGET` | exclude it (data.exclude = ["line"]), group rare values upstream, or raise preprocess.max_categories |
| f05-device-unavailable | `E_DEVICE_UNSUPPORTED` | set execution.candidate_device = "cpu" (or "auto-certified"); RustPy never falls back silently |
| f06-memory-budget | `E_RESOURCE_BUDGET_EXCEEDED` | raise execution.max_memory_mb if the machine has the memory, or use a smaller dataset / fewer categorical levels |
| f07-test-reuse | `E_TEST_SET_REUSE` | compare candidates on the validation split (`--split valid`); if you accept a biased estimate, pass --allow-test-reuse (recorded in reports and bundles) |
| f08-corrupt-bundle | `E_BUNDLE_CORRUPT` | the file was modified or damaged; rebuild the bundle or restore it from a known-good copy |
| f09-incomplete-bundle | `E_BUNDLE_MISSING_FILE` | the bundle is incomplete; rebuild it with `rustpy bundle build` or restore a complete copy |
| f10-time-split-refused | `E_SPLIT_UNSUPPORTED` | RustPy will not fall back to a random split for time-dependent data; split the file by time yourself into train/test files, or remove data.time_column if rows are truly independent |
| f11-resume-completed-run | `E_RUN_STATE_INVALID` | start a new run with `rustpy run`, or continue training from its weights with `rustpy resume run-001 --warm-start` |
| f12-missing-data-file | `E_DATA_SOURCE_NOT_FOUND` | check data.source in rustpy.toml or bind a file with `rustpy data bind <file>` |
